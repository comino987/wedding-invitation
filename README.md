# 宇誠＆婉儀｜婚禮電子喜帖 PWA 最終版

請將本資料夾內所有檔案上傳到 GitHub Pages 儲存庫根目錄：

- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root)

## Android Chrome
開啟網站 → 右上角 ⋮ → 安裝應用程式 / 加到主畫面

## iPhone Safari
開啟網站 → 分享 → 加入主畫面

此版本包含：
- 三折互動翻頁
- 下往上翻面
- 雙指縮放
- 橫向高度適配
- 橫向頁面可上下滾動
- RSVP Google 表單按鈕
- PWA standalone 模式
